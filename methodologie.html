Méthodologie EuroRare

EuroRare sépare volontairement trois notions souvent confondues : le tirage, la rareté relative et la valeur de marché. Un faible tirage peut rendre une émission plus difficile à trouver, mais il ne garantit jamais à lui seul un prix élevé.

1. Identifier avant d'estimer

Une estimation n'a de sens qu'après avoir confirmé le pays, la valeur faciale, le millésime, le motif, l'atelier ou le code imprimeur lorsque celui-ci est pertinent. Pour les erreurs de frappe ou d'impression, l'authentification est indispensable : une usure ou une détérioration après fabrication n'est pas une erreur de production.

2. Lire le tirage comme un indicateur, pas comme une cote

Pour les 2 € commémoratives, EuroRare utilise le tirage comme indicateur de disponibilité. Le niveau affiché sert à comparer les émissions entre elles. La demande, l'état, la présentation officielle, les variantes et la popularité du thème peuvent faire varier fortement le prix réel.

3. Estimer la revente à partir du marché réel

Nous privilégions les ventes conclues, les archives d'enchères et les références numismatiques spécialisées. Une annonce active à un prix spectaculaire n'est pas une preuve de valeur. Les prix boutique sont utiles pour comparer l'offre professionnelle, mais ils ne correspondent pas nécessairement au montant récupérable par un vendeur particulier.

4. Distinguer les états de conservation

Une même émission peut se négocier très différemment selon qu'elle a circulé, qu'elle est UNC/FDC, qu'elle provient d'un coincard, d'un coffret BU ou d'une présentation Proof/BE. Les fourchettes affichées doivent donc être lues avec l'état exact de l'exemplaire.

5. Sources privilégiées

Les sources institutionnelles sont prioritaires pour les caractéristiques officielles : Banque centrale européenne, Commission européenne, banques centrales nationales et ateliers monétaires. Numista et les archives de ventes sont utilisés comme repères complémentaires pour le marché.

Important : EuroRare fournit une aide à l'identification et une estimation pédagogique. Pour une pièce ou un billet de forte valeur, une expertise physique reste recommandée.
